# witness_lema_ Control

Open /admin on the deployed website and sign in with the private owner credentials.

## Publishing model

- **Save draft** stores website changes privately.
- **Preview draft** opens the private draft while the owner session is active.
- **Publish website** replaces the public version and creates a recovery point.
- **Restore to draft** copies an older public version into Draft without changing the live site.
- Assistant answers are managed separately and become live when **Save assistant answers** succeeds.

## Sections

- **Profile & links:** homepage hero text, About biography, Services introduction and public links.
- **Services:** add, reorder, edit or remove service cards.
- **Photographs:** upload optimized photos, select Home hero images and choose exactly three About images.
- **Assistant:** edit questions, answers, keywords and related page links.

Never place passwords, identification documents, private addresses or screening information in public website fields or assistant answers.
