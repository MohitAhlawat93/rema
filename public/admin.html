Safe ownership transition

Client setup & handover.

Track the work needed to make this website independent from the developer. These steps are not yet verified.

Before handing over

Ownership transfers are not performed by this page. They require account permissions, owner approval, verified backups and explicit confirmation. Do not paste API keys, passwords, recovery codes or identity documents into the admin content fields.

Choose the commercial arrangement first: managed website (developer maintains code/infrastructure under an agreement) or full handover (the client controls hosting and receives source code if contracted).

1. Business & content

Confirm the business name, public biography, service descriptions and prices, image ownership, contact methods, reviews, privacy wording and assistant answers.

Owner sign-off required · Unverified

2. Domain & Google

The owner purchases and controls a domain and Google account. Confirm production canonical URLs, HTTPS, Search Console verification and sitemap submission.

External authorization required · Unverified

3. Infrastructure & secrets

Prepare an isolated client database, hosting ownership, environment variables, client-billed AI access and backup restore. Rotate developer secrets during cutover.

Developer migration required · Unverified

4. Source-code agreement

Managed service: no GitHub access required. Full code purchase: supply a clean client-only repository and licence/assignment terms. Never hand over shared projects or personal accounts.

Signed agreement required · Unverified

5. Security & acceptance

Verify admin role separation, backups, access recovery, storage permissions, mobile images, slow connections, reviews, chatbot, WhatsApp and all public pages.

Independent launch testing required · Unverified

6. Engineering preflight

The developer runs npm run audit:handover in the source repository to locate hard-coded branding, the temporary domain, contact defaults and shared infrastructure references.

Code check only · Does not confirm external account ownership
